# Drawing Studio 3.0

Бесплатная растровая студия цифровой живописи на GitHub Pages. Работает в браузере, без сервера, платных API, аккаунтов и облачной генерации.

## Что входит в 3.0

### Настоящий движок кистей
- Встроен **MyPaint Brush Engine / libmypaint**, скомпилированный в WebAssembly.
- Подключены 36 параметрических пресетов кистей.
- Передаются координаты, давление пера, наклон и время между точками.
- Рендеринг выполняется на растровых canvas-слоях.
- Есть резервный процедурный Canvas-движок, если WebAssembly не загрузился.

### Рабочая область
- Холст 1600 × 1200.
- Кисть, ластик, карандаш, аэрограф, маркер и текстурные пресеты.
- Линия, прямоугольник, эллипс, заливка, пипетка, текст и перемещение холста.
- Масштабирование и вписывание холста.
- Палитра цветов, размер и непрозрачность мазка.

### Слои и файлы
- Несколько независимых растровых слоёв.
- Видимость, блокировка, переименование, порядок, непрозрачность.
- Режимы смешивания Canvas 2D.
- Импорт изображения в активный слой.
- Экспорт всей композиции или отдельного слоя в PNG.
- Проектный формат `.dsp` сохраняет изображения слоёв и их параметры; поддерживается открытие проектов 2.0 и 3.0.
- Undo/redo с ограниченной историей для контроля памяти.

## Структура
- `index.html` — интерфейс студии.
- `drawing-engine/app.js` — инструменты, слои, ввод пера, история, импорт и экспорт.
- `drawing-engine/mypaint-adapter.js` — адаптер приложения к MyPaint WASM.
- `drawing-engine/brushes.js` — резервный процедурный движок.
- `vendor/mypaint/brushlib.js` и `brushlib.wasm` — WebAssembly-движок.
- `vendor/mypaint/brushes.js` — набор пресетов кистей.
- `vendor/mypaint/COPYING` и `UPSTREAM.md` — лицензия и сведения об исходном проекте.

## Используемый внешний проект и лицензия

MyPaint WASM взят из [eliot-akira/brushlib-wasm](https://github.com/eliot-akira/brushlib-wasm), основанного на libmypaint v1.3.0. Использована версия исходников с commit `0953a920e090b1058e02142df28e109273e22f91`. Лицензионное уведомление libmypaint/brushlib находится в `vendor/mypaint/COPYING`; оно разрешает использование, копирование, изменение и распространение при сохранении уведомления. Полный текст включён в репозиторий.

Это настоящий движок параметрических кистей MyPaint, а не полная программа MyPaint и не физическая симуляция всех видов красок. Некоторые названия инструментов в интерфейсе выбирают ближайшие пресеты движка; они не означают, что в WASM реализована отдельная физика масла или акварели.

## Горячие клавиши
- `B` — кисть
- `E` — ластик
- `I` — пипетка
- `G` — заливка
- `H` — перемещение холста
- `Ctrl+Z` — отмена
- `Ctrl+Shift+Z` или `Ctrl+Y` — повтор
- `Ctrl+S` — сохранить проект
- `[` / `]` — размер кисти

## Запуск

Открой GitHub Pages или запусти статические файлы через локальный HTTP-сервер. Для WASM нужен браузер с поддержкой WebAssembly и загрузка файлов по HTTP(S); открытие HTML через `file://` может блокировать загрузку бинарного модуля.
