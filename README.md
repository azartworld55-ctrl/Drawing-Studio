# Drawing Studio 2.0

Бесплатная растровая студия цифрового рисования. Работает как статический сайт на GitHub Pages: без сервера, аккаунтов, платных API, токенов и внешних runtime-зависимостей.

## Что нового в 2.0
- Полностью перестроенный интерфейс с рабочей областью и боковыми панелями
- Отдельные растровые слои, видимость, порядок, непрозрачность
- Режимы смешивания слоёв: обычный, multiply, screen, overlay, darken, lighten, color dodge, soft light
- Кистевые режимы: мягкая кисть, карандаш, маркер, аэрограф, акварельная имитация, масляная кисть, ластик
- Учет давления стилуса там, где браузер и устройство передают PointerEvent.pressure
- Фигуры, заливка, текст, пипетка и перемещение холста
- Масштабирование, вписывание холста в окно, undo/redo
- Импорт изображения в активный слой
- Экспорт итоговой композиции в PNG
- Сохранение и открытие переносимого проекта .dsp (слои, прозрачность и режимы смешивания)

## Архитектура
- `index.html` — интерфейс и разметка
- `drawing-engine/app.js` — приложение, управление холстом, слоями, историей, импортом и экспортом
- `drawing-engine/brushes.js` — автономный Canvas 2D движок процедурных растровых мазков

Все операции происходят локально в браузере. В проекте нет подключения к облачной генерации изображений. Кисти — собственная процедурная реализация Canvas 2D; это не интеграция полного MyPaint/libmypaint и не физически точная симуляция краски. Для сложных картин лучше работать отдельными слоями и экспортировать PNG.

## Управление
- `Ctrl+Z` — отменить
- `Ctrl+Shift+Z` — повторить
- `Ctrl+S` — сохранить проект
- `[` / `] ` — уменьшить / увеличить кисть
- Перетаскивание холста — инструмент «Перемещение»
