# Drawing Studio

Браузерная студия на Canvas 2D. Статический GitHub Pages, без сервера, платных API и ключей.

## Возможности
- Кисть, ластик, фигуры, заливка, текст и пипетка
- Палитра, размер и прозрачность, сетка, Undo/Redo
- Открытие изображений и экспорт PNG
- Растровые авторские работы в `artworks/`

## Движок кистей
`drawing-engine/brushes.js` — автономные бесплатные Canvas 2D helpers: текстурированные мазки, управляемый разброс частиц, мягкое свечение и зерно холста. Подключён к странице и не требует сетевых запросов.

## Изученные открытые проекты
- [Pillow](https://github.com/python-pillow/Pillow) — растровое рисование и PNG.
- [NumPy](https://github.com/numpy/numpy) — массивы пикселей и математика.
- [libmypaint](https://github.com/mypaint/libmypaint) — движок натуральных кистей (ISC).
- [glbrush.js](https://github.com/Oletus/glbrush.js) — текстурированные кисти (MIT).
- [p5.brush](https://github.com/acamposuribe/p5.brush) — карандаш, уголь, маркеры, акварель.
- [Brush Nodes](https://github.com/Keavon/Brush-Nodes) — процедурные текстуры.
- [Brush Renderer](https://github.com/madblade/brush-renderer) — painterly rendering (MIT).
- [OpenCV](https://github.com/opencv/opencv) и [scikit-image](https://github.com/scikit-image/scikit-image) — обработка изображений.

Внешние проекты не копируются в приложение. Студия остаётся самостоятельной и бесплатной.
