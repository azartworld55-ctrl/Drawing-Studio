# Drawing Studio

Небольшая браузерная студия для рисования на HTML Canvas. Работает как статический сайт через GitHub Pages — сервер и API-ключи не нужны.

## Возможности

- Кисть и ластик с настройкой размера и непрозрачности
- Линии, прямоугольники и эллипсы
- Заливка области по границе цвета (bucket fill)
- Добавление текста на холст
- Пипетка для выбора цвета с холста
- Включаемая сетка для аккуратного рисования
- Палитра цветов
- Отмена и повтор действий
- Открытие изображения для рисования поверх
- Экспорт результата в PNG
- Поддержка мыши, стилуса и сенсорного экрана

## Запуск

Откройте `index.html` в браузере. Для публикации через GitHub Pages выберите ветку `main` и папку `/(root)` в Settings → Pages.

## Проекты с открытым исходным кодом, которые мы изучили

При развитии редактора полезны идеи и возможности этих проектов:

- [Fabric.js](https://github.com/fabricjs/fabric.js) — объекты, текст, трансформации и экспорт.
- [Konva.js](https://github.com/konvajs/konva) — интерактивные сцены и работа с холстом.
- [Atrament](https://github.com/jakubfiala/atrament) — плавное рисование и рукописные линии.
- [Rough.js](https://github.com/rough-stuff/rough) — эскизные, нарисованные от руки фигуры.

Сейчас Drawing Studio остаётся лёгким самостоятельным приложением без обязательных внешних библиотек; эти проекты указаны как источники идей и возможные направления развития.
